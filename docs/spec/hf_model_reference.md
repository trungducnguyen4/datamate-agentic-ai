# Qwen3-0.6B DataMate IR Adapter

LoRA adapter fine-tuned for Vietnamese DataMate semantic parsing. The model
converts a question, `as_of_date`, and business schema/rulebook into structured
JSON IR for the downstream compiler and execution engine.

## Training results

| Metric | Result |
|---|---:|
| Base model | `Qwen/Qwen3-0.6B` |
| Method | QLoRA 4-bit NF4 |
| Train / validation examples | 2,446 / 554 |
| Validation split | By `business_id` |
| Epochs | 3 |
| Train loss | 0.05457 |
| Validation loss | 0.00612 |
| Train runtime | 1,744.68 s (~29.1 min) |
| Train samples/s | 4.206 |
| Validation samples/s | 21.506 |
| Hardware | NVIDIA GeForce RTX 5090, 31.8 GB VRAM |

Training targets are weak-supervision IR labels generated by the deterministic
B1 parser. Prompts and targets do not contain final numeric answers.

## End-to-end evaluation results

Evaluation uses all 1,000 questions in `data/public_test`, the conservative
semantic compiler, and the same answer evaluator as the deterministic baselines.

| Total | Correct | Wrong | Abstain | PA | Accuracy | Coverage | Selective accuracy |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 1,000 | 8 | 3 | 989 | 0.005 | 0.8% | 1.1% | 72.73% |

| Execution metric | Result |
|---|---:|
| Execution success rate | 1.1% |
| Abstain rate | 98.9% |
| Wrong rate | 0.3% |
| Latency p50 | 446.801 ms/question |
| Latency p95 | 518.121 ms/question |

The model produced 11 executable answers: 8 correct and 3 wrong. Low validation
loss on weak IR labels does not imply high end-to-end PA; temporal parsing and
compiler coverage remain the main limitations.

Run the full evaluation with:

```bash
./scripts/evaluate_finetuned.sh
```

## Limitations

- IR targets are pseudo-labels rather than manually reviewed gold annotations.
- Temporal abbreviations and noisy Vietnamese can be resolved incorrectly.
- The safe compiler currently executes only `cancel_count`, `cancel_rate`, and
  `purchase_total`; other plans abstain.
- This is a LoRA adapter and requires the `Qwen/Qwen3-0.6B` base model.
